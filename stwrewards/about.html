About This Site

STW Daily is a simple student project made for people who play Fortnite Save the World. The goal is to make daily rewards easier to read in a simple website.

The site uses HTML, CSS, and JavaScript. The JavaScript reads data from arrays of objects and displays it on the page. Users can also filter missions by reward type.

This project is not connected to Epic Games. It is only a fan-made class project.
