STW Daily - Site Plan

Purpose

This site helps Fortnite Save the World players quickly view daily llamas and mission rewards. It makes it easy to see what is worth doing each day.

Audience

The audience is Fortnite Save the World players who want quick and simple access to daily information. It is useful for both new and experienced players.

Dynamic Elements

JavaScript will display daily llamas and missions using arrays and objects. Users can filter missions by reward type, click buttons for details, and sort rewards. DOM updates and event listeners will handle interactions.

Logo

A simple Fortnite-themed logo with a llama icon and bold text like “STW Daily”.

Colors

Dark background with blue and purple accents, similar to Fortnite’s style.

Fonts

Use a bold display font for headings and a simple sans-serif font for content.

Content

Daily llamas, daily missions, reward types, reward amounts, and short descriptions.
