About STW Daily

STW Daily is a website concept built for Fortnite Save the World players. Its main purpose is to help players quickly check daily llamas and mission rewards in a clean and simple format.

Purpose

This project helps players save time by showing important daily information in one place. Instead of scanning through long lists or outside tools, a player can visit the site and immediately find the rewards that matter most to them.

Audience

The audience includes both new and experienced Save the World players. Newer players can use the reward labels and descriptions to understand what is useful, while experienced players can quickly decide which missions are worth farming that day.

Content

The site includes daily llamas, daily missions, reward types, reward amounts, and short descriptions. These sections give players meaningful text content while also making the site more understandable and readable.

Design

The design uses a dark background with blue and purple accents inspired by Fortnite’s visual style. Headings are bold and clear, while the page content uses a simple readable sans-serif font. The layout is mobile first and becomes wider and more spacious on larger screens.

JavaScript Features

The site uses arrays and objects to store llama and mission data. JavaScript then displays that data on the page, filters mission rewards, sorts results, updates text in the DOM, and reacts to user input with event listeners. This supports the project requirements for dynamic interactivity.

STW Daily is a student project inspired by Fortnite Save the World daily information tools.
